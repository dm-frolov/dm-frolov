### [Olist Sales Analytics — анализ продаж маркетплейса](https://github.com/dm-frolov/olist-sales-analytics)

**PostgreSQL · SQL · Power BI · Power Query · DAX**

Анализ исторических данных бразильского маркетплейса Olist: заказы, товары, покупатели и платежи.

- Загрузил данные из CSV в PostgreSQL и подготовил схему из семи связанных таблиц.
- Проверил количество записей и целостность связей; подготовил SQL-запросы с `JOIN`, `GROUP BY`, CTE и оконными функциями.

- Собрал модель данных и интерактивный дашборд в Power BI с мерами DAX.
- Документировал методологию расчётов и ограничения показателей, включая различие между стоимостью товаров и суммой платежей.

### [MAGIC Gamma Telescope — анализ данных и классификация](https://github.com/dm-frolov/magic-gamma-classification)

**Python · pandas · scikit-learn · LightGBM · Matplotlib**

Проект по анализу 19 020 наблюдений телескопа MAGIC и классификации событий.

- Провёл разведочный анализ данных: распределения признаков, баланс классов, пропуски, дубликаты и корреляции.
- Подготовил данные и сравнил несколько алгоритмов с использованием стратифицированной кросс-валидации и `Pipeline`.
- Получил средний F1 **0,9115** на кросс-валидации для LightGBM и ROC-AUC **0,9425** на тестовой выборке.
- Проанализировал матрицу ошибок и ограничения эксперимента; детали оценки приведены в репозитории.

[Код и результаты](https://github.com/dm-frolov/magic-gamma-classification)
